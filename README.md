# Hydizo — Landing Page + Pricing Section

Take-home task for Hydizo Global Solutions PVT LTD: a fully responsive landing page with a pricing section, built with **React + Tailwind CSS** (Vite).

## Live demo
GitHub Pages: https://kmsasikumar.github.io/hydizo-landing-page/

## What's inside
- Sticky navbar with mobile menu
- Hero section
- Features grid
- Pricing section — monthly/yearly toggle ("2 months free" on yearly), 3 tiers, popular-plan highlight
- FAQ accordion
- Footer

Fully responsive (mobile → desktop).

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
